# Young's Double-Slit Interference Simulation

## 📐 Physics Principles & Formulas
This project simulates the optical interference pattern of monochromatic light passing through a double slit using Python.

* **Fringe Spacing Formula**: 
  $$\Delta x = \frac{L}{d} \lambda$$
* **Intensity Distribution Formula**: 
  $$I = 4I_0 \cos^2\left(\frac{\pi d x}{\lambda L}\right)$$

*(Note: $\lambda$ is the wavelength, $d$ is the distance between the slits, and $L$ is the distance from the slits to the screen.)*
